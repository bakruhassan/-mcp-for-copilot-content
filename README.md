After going through all five PDFs, I would actually change the session design completely.

Right now you're trying to teach leaders about AI.

I think the stronger approach is:

"I'm not here to show you Copilot. I'm here to give you 4 leadership habits you can use tomorrow morning."

And the CopilotTips prompts become the exercises.

My Recommendation
Theme
AI for Leaders: Three Moments That Matter

Not:

Opening (5 mins)

Instead of starting with Custom Instructions as suggested in the runbook, I would keep it lighter.

Say:

Over the last few months at Swift, I've realised that AI becomes useful only in three moments:

When I need to regain context
When I need to make a decision
When I need to drive accountability

Today we're going to experience all three.

Then show a QR code with the prompts.

The Custom Instructions Template should be positioned as a takeaway, not the opening exercise.

Activity

Ask every leader:

Think of one real decision you need to make this month.

Then use the Strategy Consultant Prompt.

The prompt is designed to:

identify the governing question
structure the problem using MECE logic
diagnose root causes
surface risks
recommend actions
build an implementation roadmap
generate a risk and control matrix

while avoiding invented data.

Pair Discussion

Ask:

Did it surface something you had not considered?

This becomes the most valuable discussion.

Leadership Message

AI doesn't make the decision.

AI reduces blind spots before the decision.

AI will not make you a better leader.
